# 2026-09-25 開発履歴

## Post画像の閲覧と編集

- 投稿済み画像をクリックまたはタップすると、背景を暗くしたライトボックスで拡大表示できるようにした。
- 複数画像では前後の画像へ移動できるようにし、PCではEscapeキーでも閉じられるようにした。
- Post編集画面に既存画像を表示し、画像ごとに「削除予定」を設定できるようにした。削除予定は保存時までDB・Storageへ反映しない。
- Post編集画面から新しい画像を追加し、保存前に取り消せるようにした。
- 既存の画像変換・アップロード処理を再利用し、保存後に残る既存画像と追加画像の合計を最大4枚に制限した。

## RLSの確認事項

- 管理者が他ユーザーのPostへ画像を追加できるよう、`supabase/schema.sql`に管理者向けの`post_images`追加ポリシーを追加した。
- Supabaseへの適用はこの時点では行っていない。

## Topic編集権限の変更

- Topic編集を作成者本人または管理者に限定し、画面上でもそれ以外のユーザーに編集ボタンを表示しないようにした。
- `supabase/schema.sql`のTopic更新RLSを、作成者本人または管理者だけが更新できる条件へ変更した。
- Topic削除は管理者のみのまま維持した。
- 現在使用中のSupabaseプロジェクトには、更新後のTopic RLSと管理者向けの画像追加RLSを手動で適用する必要がある。

## 確認

- `npm run lint`、`npm run build`、`git diff --check`は成功した。
- ブラウザとSupabaseを使用した画像の追加・削除・管理者操作の手動確認は残っている。
