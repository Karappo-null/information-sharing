# 現在の開発状態

最終更新: 2026-09-20

## 現在実装済みの機能

- メールアドレス・パスワードによる登録とログイン
- 表示名の登録と画面表示
- Topicの作成・編集・管理者による削除
- Postの作成・投稿者本人または管理者による編集・削除
- Postへの画像添付・削除
- Postへの一段階コメント・編集・削除
- `member` / `admin` による権限分けとRLS
- SupabaseのDB、Storage、RLSを作成するSQL

## 判明している不具合

### 確認済み

- Comment送信後、非同期保存の完了時点でフォーム参照が`null`になり、一覧再取得前に例外となる不具合があった。2026-09-20に修正した。
- Post・Commentのプロフィール結合結果を配列として参照していたため、表示名を取得できず「メンバー」と表示される不具合があった。2026-09-20に修正した。

### 要確認

- 画像アップロード・削除、RLS、Supabase Auth設定を現在のSupabaseプロジェクトでどこまで検証済みかは、ソースコードからは判定できない。

## 現在の課題

- 2026-09-19に`origin/main`の未取り込み2コミットを取り込み、PostとCommentの表示順を新しい順に統一した。取り込み前の変更は`backup-docs-and-profile-query`ブランチにも保存されている。
- 画像のStorageファイル削除は画面操作で行う。ネットワーク失敗時に孤立ファイルが残る可能性への対策は未実装。
