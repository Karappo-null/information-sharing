# Shareboard MVP 仕様

最終更新: 2026-08-30

## 目的

友人グループが、自由な話題ごとに情報を共有するための最小構成のWebアプリ。完成度よりも、実際に使って必要な機能を見極めることを優先する。

## 利用者と公開範囲

- 利用者は自分と友人グループ。
- アカウント登録とログインは必須。
- 未ログインの利用者はTopic、Post、コメント、画像を閲覧できない。
- ログイン済み利用者は、すべてのTopic、Post、コメント、画像を閲覧できる。
- Topicごとの公開範囲、参加者制限、グループ機能は設けない。

## User

- 認証方式はメールアドレスとパスワード。
- 登録時に表示名を入力する。
- 表示名は1〜30文字、重複を許可する。
- メールアドレスは他の利用者へ表示しない。
- 表示名はMVPでは変更できない。
- 役割は `member`（一般ユーザー）と `admin`（管理者）。
- 初期管理者はSupabaseのSQL Editorから手動で設定する。

### 登録運用

- URLは友人にだけ共有する。
- 登録受付中だけSupabase Authの新規登録を有効にする。
- 友人の登録後、Supabase Authで新規登録を停止する。
- メールアドレス確認は行わない。

## Topic

Topicは、雑談、旅行、映画、仕事、趣味など、自由な話題を表す単位。

| 操作 | member | admin |
|---|---:|---:|
| 閲覧 | 可 | 可 |
| 作成 | 可 | 可 |
| 編集 | 可 | 可 |
| 削除 | 不可 | 可 |

- Topicはタイトル（1〜100文字）と任意の概要（最大280文字）を持つ。
- 作成者を記録・表示する。

## Post

PostはTopicに属する個別の投稿。

| 操作 | 投稿者本人 | 他のmember | admin |
|---|---:|---:|---:|
| 閲覧 | 可 | 可 | 可 |
| 作成 | 可 | 可 | 可 |
| 編集 | 可 | 不可 | 可 |
| 削除 | 可 | 不可 | 可 |

- Post本文は1〜5,000文字。
- 投稿者を記録・表示する。
- Postの移動（別Topicへの付け替え）は行わない。

## 画像

- 画像はPostにのみ添付できる。コメントには添付できない。
- 1つのPostあたり最大4枚。
- 選択可能な形式はJPEG、PNG、WebP。
- 選択時の最大サイズは1枚5MB。
- ブラウザ内で長辺1920px以内、WebP品質0.82へ変換してから保存する。
- 元画像はSupabaseへ送信・保存しない。
- 画像の追加はPost作成時のみ。投稿後は削除のみ可能。
- 画像削除は投稿者本人または管理者が行える。

## コメント

- コメントはPostに対する一段階のみ。
- コメントへの返信（入れ子構造）は作らない。
- コメント本文は1〜2,000文字。
- コメントの編集・削除は、コメント投稿者本人または管理者が行える。

## MVPで実装しないもの

- 一般ファイル添付
- URLプレビュー、Markdown
- リアクション、メンション、通知、検索
- コメントへの返信
- Topicごとの参加者・公開範囲
- 複数グループ・複数組織
- プロフィール画像、表示名の変更
- 高度な管理画面

これらは、実際の利用で必要性が確認できてから検討する。
