## プロジェクトの目的

既存のREADMEと仕様文書では、Shareboardは友人グループ向けの認証付き情報共有アプリと説明されている。

より詳しい背景や、なぜこのアプリが必要になったかは、リポジトリ内の資料からは確認できない。**要確認**。

## 解決したい問題

Topic（自由な話題）ごとに、Post、コメント、画像をまとめて共有できるようにする。

Topicの具体的な用途や、既存のどの手段を置き換えるかは未確認。

## 想定利用者

既存仕様文書では「自分と友人グループ」を対象としている。利用人数、利用頻度、公開後の対象範囲は未確認。

## アプリの基本構造

```text
ログインユーザー
  └─ Topic（自由な話題）
       └─ Post（本文・画像）
            └─ Comment（一段階のコメント）
```

ログイン済みユーザーはすべてのTopic、Post、コメント、画像を閲覧できる構成である。詳細な権限は [design.md](./design.md) を参照。

## 現在の主要機能

- メールアドレスとパスワードによる登録・ログイン
- 表示名の登録と表示
- Topicの作成・編集・管理者による削除
- Postの作成・編集・削除
- Postへの画像添付
- Postへの一段階コメント
- Topic、Post、Commentを対象とした横断検索
- 一般ユーザーと管理者の区別

## 使用技術

- Next.js / React: ブラウザで動く画面
- Supabase Auth: アカウント登録・ログイン
- Supabase Postgres: Topicなどのデータ保存
- Supabase Storage: 投稿画像の保存
- Vercel: READMEでは公開先として想定されている

Vercelへ実際にデプロイ済みかは、リポジトリからは確認できない。
